# MotoVoid IA para Android 2.3

Un pequeño modelo de reglas, hecho por clause velocidades locas, que corre sin internet en Android 2.3 (API 9) o más nuevo.

Qué sabe hacer: platicar con tono amable, matemáticas con explicación paso a paso (cuentas, porcentajes, ecuaciones, sistemas, Pitágoras, áreas, promedio), historia básica, versiones de Android, teléfonos Samsung Galaxy S e iPhone, RAM y qué app usar para videos en Android viejo.

## Cómo sacar el APK desde GitHub
1. Sube todo el contenido de esta carpeta a tu repositorio (Add file > Upload files).
2. Entra a la pestaña **Actions**. La compilación empieza sola (tarda unos 3 a 6 minutos).
3. Cuando salga la palomita verde, abre esa ejecución y baja a **Artifacts**.
4. Descarga **MotoVoid-IA-apk**, descomprime el zip y pasa el archivo `.apk` al teléfono.
5. En Android 2.3: Ajustes > Aplicaciones > activar **Orígenes desconocidos**, y abre el APK para instalar.

Si algo falla en Actions, copia el texto del error y envíamelo.
